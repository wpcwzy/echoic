| 项目 | 内容 |
|---|---|

## 1. 信息架构与导航

```
Echoic
├── /login                登录
├── /                     资料库（默认）：统计 / 筛选 / 卡片 / 上传
├── /record               录音与上传：麦克风 / 拖拽 / 最近上传
├── /r/:id                详情：播放器 + 转写|AI纪要|观点树|章节 + AI 面板
├── /search               全局搜索：录音 / 转录片段（带时间点）
└── /settings             设置：AI 服务 / 提示词 / 系统 / 账户 / 关于
```

| 路由 | 导航位置 | 关键规则 |
|---|---|---|
| `/login` | 无 | 未登录唯一可达；成功后回跳 `from` 或 `/` |
| `/` | 左栏第 1 项 | 筛选/排序/视图写入 URL，刷新与后退可恢复 |
| `/record` | 左栏第 2 项 | 先检查 `getUserMedia` 与安全上下文（HTTPS/localhost） |
| `/r/:id` | 卡片 / 搜索结果 | 支持 `?tab=transcript` 等四个 Tab 参数与 `?t=毫秒` |
| `/search` | 左栏第 3 项 / 顶栏 | 顶栏弹层检索，Enter 进结果页 |
| `/settings` | 左栏底部 | AI 配置仅管理员；账户/关于所有人可见 |

- 左栏固定 64px：Logo、资料库、录音、搜索、设置、底部用户；激活项浅蓝底 + 主色图标 + 3px 左侧指示条。
- 顶栏固定 56px：面包屑（详情页）、全局搜索、上传按钮、演示模式标识、用户菜单。
- ≤768px：左栏变底部 4 项导航；详情页 AI 面板变 Drawer；播放器吸顶。

## 2. 核心用户旅程

### 2.1 J1 首次部署 → 配置密钥 → 上传 → 阅读

| 步骤 | 用户动作 | 界面反馈 | 失败出口 |
|---|---|---|---|
| 1 | `docker compose up -d` 后打开 `http://host:8000` | 登录页 + 版本/health 状态 | 端口/卷权限/ffmpeg 缺失：给出可复制的排查提示 |
| 2 | 用默认管理员登录 | 进入资料库；有示例数据时顶部提示 | 密码错误统一提示；连续失败显示限速倒计时 |
| 3 | 设置 → AI 服务：选 Provider、填 Key、测试、保存 | 连接成功显示延迟；保存后变“已配置”，演示模式条消失 | Key/网络失败不阻塞保存，但标“未验证”并给出检查项 |
| 4 | 上传或录音 | 进度 → `queued` → 详情页进度卡 | 超限/格式错就地提示，可直接换文件 |
| 5 | 等待处理（可离开） | 阶段中文 + 进度条 + 预计说明；可取消 | 失败显示原因 + “重试处理” |
| 6 | 看纪要/观点树/章节，提问，导出 | 内容 Tab 化；时间戳可点；SSE 流式回答 | 某类 AI 缺失只影响该卡片，可单类重算 |

**首次价值**：演示数据 ≤3 分钟看到完整纪要；真实上传 ≤ 处理时长 + 2 分钟。

### 2.2 J2 网页录音 → 入库

`开始录音 → 请求麦克风 → 选设备 → 录制/暂停 → 停止 → 试听 → 重录或保存 → 上传(source=browser_recording) → 详情页`

- 权限拒绝/无设备说明原因并提供“改为上传文件”；中断保留片段；上传失败保留 Blob 可重试。

### 2.3 J3 阅读 → 问答 → 回听；J4 搜索复用；J5 无 Key 演示

| 旅程 | 路径与关键反馈 |
|---|---|
| J3 问答 | 默认 Tab=有纪要则 AI纪要 → 点 `[12:05]` 引用 → seek + 转写高亮 2s → 猜你想问直接发送 → 追问保留 6 轮 → 可清空 |
| J4 搜索 | 顶栏输入 → 弹层分组 → Enter 结果页 → 点片段 → `/r/:id?t=385000&tab=transcript` → 自动 seek 高亮 → 复制/导出 |
| J5 演示 | 首次启动 seed 示例 → 顶部“演示模式”细条（可关闭）→ 上传真实音频时 Mock 生成转写并显式标注，避免误认 |

### 3.2 录音与上传、登录、搜索、设置

| 页面 | 关键交互 |
|---|---|
| 录音与上传 | 状态机 `idle→requesting→recording⇄paused→stopped→uploading→done`；暂停时计时停、电平归零；保存前可试听；重录需确认；多文件顺序上传（不并行，避免 SQLite/带宽争抢），单项失败不阻断后续 |

- 三栏 64 / `minmax(0,1fr)` / 400px；主内容内边距 24px；右栏 `border-left:1px solid #eceef1`、背景 `#f7f8fa`；主内容与面板各自滚动，Tab 栏吸顶，≥1600px 内容居中、面板贴边。

### 4.2 播放器卡片

| 元素 | 规格与行为 |
|---|---|
| 卡片 | 高 96px、圆角 16、内边距 16×20；浅蓝灰渐变 `#eef3fb → #f7f9fd`（截图基准） |
| 进度与时间 | 轨道 4px `#dfe6ef`，已播 `#1677ff`，拖拽点 12px；12px tabular-nums 时间（>1h 用 `hh:mm:ss`）；点击/拖动 seek，hover 时间气泡 |
| 发言人 | 24px 首字头像，最多 4 个 + “+3”；hover 显示姓名/占比，点击过滤转写 |
| 控制 | ⟲15 / 播放暂停 / ⟳15，32px 点击区；Space、←/→ 同步；倍速 0.75–2.0 记忆 |
| 更多 | 下载原文件、导出转写、重新处理、删除；危险操作二次确认 |

原生 `<audio>`/`<video>` 指向 `/api/recordings/{id}/media`（Range）；无媒体时禁用控件并显示“无媒体文件”。播放 250ms 更新进度；用户手动滚动后 3 秒内不强制跟随。

### 4.3 四个 Tab

| Tab | 内容 | 交互 | 生成中/缺失 |
|---|---|---|---|
| 转写 | 工具条（搜索/导出/说话人）+ 连续段落 | 时间戳 seek；说话人改名；段落内联编辑；当前段高亮 | 骨架屏；失败显示重试 |
| AI纪要 | Markdown + 洞察卡 + 待办 Checkbox + 关键词 Tag | 复制 Markdown；单类重算；待办本地勾选 | “生成纪要”/骨架 |
| 观点树 | 根主题 pill + 分组卡片 + 缩进观点 | 点击 seek；hover 时间/说话人；task/risk 标签 | “生成观点树” |
| 章节 | 区间 + 标题 + 摘要 + bullets | 点击跳转；当前章高亮；↑↓ 切换 | “生成章节” |

默认 Tab：有 summary → AI纪要，否则转写。转写内搜索只过滤本场，不影响全局搜索状态。说话人改名仅影响转写与后续生成，不回溯替换已有 AI 文本（UI 需说明）。

### 4.4 观点树视觉

- 根主题：浅绿 pill（`#eaf6ef` / `#1f6f52`，圆角 999，内边距 6×14），1px 竖线连到分组。
- 分组卡：`#f3f8f5` 底、`#dcebe2` 边框、圆角 12、内边距 16、间距 12；标题 15px/600。
- 观点行：6px `#2f9e7f` 圆点 + 14px/500 标题 + 13px `#7b8b84` 说明（最多 2 行）；行高 ≥40px；hover 底色 `#e9f3ee` 并浮出 `12:05 · 吴克强`，点击 seek 且高亮 2s。
- 类型标签：task `#fff7e6/#d48806`，risk `#fff1f0/#cf1322`；point 不加标签，减少噪音；最多 3 层。

### 4.5 右侧 AI 面板

- 顶部两个等宽入口：思维导图（`#eaf2ff/#1f5fbf`）、关键洞察（`#f2edff/#6b46c1`），高 64、圆角 12。
- “猜你想问”最多 6 条（来自 `suggested_questions`），点击即发送后置灰；空态给 3 条示例。
- 消息：用户右对齐蓝底白字（≤85%）；AI 左对齐白底细边框，Markdown；引用 chip `[12:05]` 可点击 seek。
- 流式与输入：光标闪烁，发送变“停止”（abort），停止后保留内容并标“已停止”；3 行自适应 TextArea，Enter 发送、Shift+Enter 换行，空输入禁用，>2000 字提示。
- <1280px 默认收起为右下悬浮按钮，打开 400px Drawer；关闭后焦点回按钮。

### 4.6 Modal 与联动

- 思维导图：`92vw × 86vh`（≤1280×800），React Flow + dagre 左→右；节点按 kind 着色；滚轮缩放、拖拽、fitView、MiniMap；点击节点 seek 并关闭；Esc/焦点陷阱。
- 关键洞察：720px，按 decision/risk/insight/opportunity 分组；待办 Checkbox；底部“复制全部”。
- 联动：转写时间戳→seek；观点节点→seek+切转写+高亮；章节→seek；引用 chip→seek+高亮 2s；说话人头像→过滤；全局片段→`?t=` seek。无媒体时只高亮不播放；引用源被删则提示“引用已失效”。

### 4.7 与参考截图的差异（待确认）

- 播放器按截图做浅蓝灰渐变；`FRONTEND.md` 的“白色卡片”需回写（D-01）。左栏用 Echoic 自有导航，不复刻飞书多产品图标/系统窗口控件。
- 截图有“分享”主按钮，v0.1 无分享，改为下载/更多，不展示不可用入口。

## 5. 状态设计

| 状态 | 界面表现 | 出口 |
|---|---|---|
| 空资料库 | 插画 + 上传/录音 + 载入示例 | 两个主按钮 |
| 加载 | 统计卡/卡片骨架屏，不用满屏 spinner | 自动结束 |
| 上传中 | 单项进度 + 取消；队列可继续添加 | 取消/重试 |
| 处理中 | 阶段中文 + 进度条 + 说明 + 取消；卡片显示百分比 | 可离开页面 |
| 部分生成 | 缺失卡片“未生成/重新生成”，其余正常 | 单类重算 |
| 失败 | 红色状态条 + 中文原因（provider/HTTP，无密钥）+ 重试 | 重试/删除/改配置 |
| 演示模式 | 顶部细条 + 设置标识 + AI 内容“示例”标签 | 关闭提示/去配置 |
| 无媒体 | 播放器禁用 + “媒体文件不可用” | 重新上传（P1） |
| 搜索无结果 | 文案 + 建议 + 清除筛选 | 改词/回资料库 |
| 会话过期 | 登录页 + “登录已过期” | 登录后回跳 |

| stage | 中文 | 说明 |
|---|---|---|
| `preparing` | 准备音频 | 解析时长并生成可播放版本 |
| `transcribing` | 转写中 | 识别说话人与文字，长录音更久 |
| `analyzing` | 生成纪要 | 提炼结论、观点树与章节 |
| `embedding` | 建立索引 | 为问答建检索索引（可跳过） |
| `finalizing` | 收尾 | 马上就好 |
| `failed` | 处理失败 | 查看原因；可重试或换模型 |

进度 2s 轮询，`ready/failed/cancelled` 停止；数字不倒退，阶段切换即时更新。

## 6. 设计规范

| Token | 值 | 用途 |
|---|---|---|
| `--color-primary` | `#1677ff` | 主按钮、进度、选中、图标（白字对比约 3.6:1，不用于 14px 正文） |
| `--color-primary-text` | `#0958d9` | 正文链接、可点击文字（≥5.9:1） |
| `--color-bg` / `surface` | `#f5f6f7` / `#ffffff` | 页面底 / 卡片 |
| `--color-border` | `#eceef1` | 分割线、卡片描边（主要分层手段） |
| `--color-text` / `secondary` / `tertiary` | `#1f2329` / `#646a73` / `#8f959e` | 正文 / 次要（5.6:1）/ 占位（仅辅助） |
| `--color-green-bg` / `purple-bg` | `#f2f7f4` / `#f2edff` | 观点树卡片 / 关键洞察入口 |
| `--color-warning` / `danger` | `#d48806` / `#cf1322` | 处理中、任务 / 失败、风险 |

- **字体**：`Inter, "PingFang SC", "Microsoft YaHei", system-ui`；数字 tabular-nums。字号 28/20/16/14/13/12；字重 600/500/400；标题行高 1.3、正文 1.6、转写 1.75；纪要最大宽度 760px。
- **间距/圆角/阴影**：4 的倍数（4–40）；卡片内边距 20–24；按钮/输入 8、卡片 12、播放器/Modal 16、pill 999；默认阴影 `0 1px 2px rgba(31,35,41,.06)`，浮层 `0 8px 24px rgba(31,35,41,.08)`，优先用 1px 描边分层。
- **图标/头像**：`@ant-design/icons` 16/20/24；头像为圆形色块 + 姓名首字，8 色盘按 speaker id 分配，不引外链图片。
- **动效**：hover 120ms、面板 200ms、Modal 240ms、进度数值 300ms；`cubic-bezier(0.2,0,0,1)`；只动 transform/opacity；`prefers-reduced-motion` 关闭位移与光标闪烁。

## 7. 可访问性与移动端

- 焦点可见（2px 主色外描边 + 2px offset）；Modal 焦点陷阱、Esc 关闭、焦点归还触发元素。
- 键盘：Space 播放/暂停，←/→ ±15s，Tab 顺序随视觉；转写段落可聚焦、Enter seek。
- 语义：`main/nav/aside`；Tab 用 `role=tablist/tab/tabpanel`；进度 `role=progressbar` + `aria-valuenow`；流式回答完成时 `aria-live=polite` 播报，不逐字播报。
- 对比度：正文 ≥4.5:1，主色仅用于大字/图形；状态不只靠颜色，配文字/图标；自动跟随可关闭。
- 移动端：底部导航；统计卡横滑、卡片单列、筛选进 Sheet；播放器吸顶 72px；AI 面板 Drawer 85vh 并随键盘上移。
- 移动录音：需 HTTPS；iOS Safari 产 mp4、Android Chrome 产 webm；来电/切后台可能中断，提前提示。触控目标 ≥44px，hover-only 操作在移动端常显。

## 8. 文案规范

**友好、克制、准确**：像可靠同事，不卖萌、不夸张、不甩锅；用“你”；陈述事实并给下一步。

| 原则 | 做 | 不做 |
|---|---|---|
| 具体 | “转写需要 3–5 分钟，可以先离开页面” | “正在努力处理中…” |
| 可行动 | “API Key 无效，请到设置 → AI 服务更新后重试” | “请求失败” |
| 不夸大 | “AI 生成，请核对原文” | “精准无误”“一键完美” |
| 不责怪 | “这个文件超过了 2GB 限制” | “你的文件非法” |

- 失败：“转写没有完成：阿里云返回 401（API Key 无效）。请到设置 → AI 服务检查密钥，然后重试。”
- 无依据：“转录稿中没有提到这一点。你可以换一种问法，或查看相关章节。”
- 按钮用“动词 + 对象”（上传录音、重新生成、重试处理），避免裸“确定”；危险操作写具体后果。
- 时间：播放器 `mm:ss`（>1h `hh:mm:ss`）；列表 `YYYY-MM-DD HH:mm`；中文与数字间加空格（“2 GB”）；技术名词保留英文。
