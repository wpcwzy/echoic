## 2. 角色与权限模型（R-18）

### 2.1 角色

- `admin`：全部权限（所有录音、用户管理、设置、系统、分享管理）。
- `member`：仅自己的录音（`recordings.owner_id == user.id`）；可上传/录音（归属自己）、编辑/删除自己的录音、创建分享；可查看标签目录；不能访问设置/用户管理/系统/演示数据。
- 兼容：保留 `users.is_admin` 布尔列，`role` 变更时同步维护（`is_admin = role=="admin"`）。权限判断以 `role` 为准（旧数据回填后一致）。

### 2.2 权限矩阵

| 能力 | admin | member | 未登录 | 公开分享 |
|---|---|---|---|---|
| 录音列表/详情/搜索/仪表盘 | 全部 | 仅自己 | 401 | — |
| 上传/网页录音 | 是（owner=自己） | 是（owner=自己） | 401 | — |
| 媒体/转录/见解/问答/重算/取消 | 全部 | 仅自己 | 401 | token + 可选密码 |
| 修改录音（标题/标签/owner） | 全部（可改 owner） | 仅自己（不可改 owner） | 401 | — |
| 删除录音 | 全部 | 仅自己 | 401 | — |
| 分享创建/列表/撤销 | 全部 | 仅自己录音 | 401 | — |
| 标签：查看 | 全部 | 全部 | 401 | — |
| 标签：创建/编辑/删除 | 是 | 否 | 401 | — |
| 设置/提示词/Provider 测试 | 是 | 否（403） | 401 | — |
| 用户管理 / 系统信息 / 日志 / 演示数据 | 是 | 否（403） | 401 | — |
| consume 扫描 | 是 | 否 | 401 | — |
| 健康检查 | 公开 | 公开 | 公开 | 公开 |

- 不可见资源统一 **404 NOT_FOUND**（不泄露存在性）；权限不足但资源可见的操作（如 member 改 owner、非 admin 写设置）返回 **403 FORBIDDEN**。
- 401：未登录/会话失效/账号停用。

### 2.3 认证变更

- `POST /api/auth/login`：停用账号返回 403 `账号已被停用，请联系管理员`；成功后更新 `last_login_at`。
- `GET /api/auth/me` 返回 `UserOut`：`{id, username, display_name, email, role, is_admin, disabled, created_at, last_login_at}`。
- `POST /api/auth/register`（受开关控制，默认关闭）：`{username,password,display_name?,email?}` → 201 `UserOut`（role=member）；关闭时 403 `FORBIDDEN`；用户名重复 409。
- 账号停用后其现有 JWT 立即失效（每次请求查库校验）。
- 改密仅本人；管理员可通过 `/api/users/{id}/reset-password` 重置。

### 迁移策略
- `app/migrations.py::run_migrations()` 在 `init_db()` 之后、账号初始化之前执行；幂等。
- 用 SQLAlchemy inspector 检查列缺失，按方言执行 `ALTER TABLE users ADD COLUMN ...`（SQLite：`BOOLEAN DEFAULT 0`；Postgres：`BOOLEAN DEFAULT FALSE`），随后回填 `role='admin' WHERE is_admin=true`、`disabled=false`。
- 新表由 `Base.metadata.create_all()` 创建；无需手工 SQL。
- 现有记录 `owner_id` 保持（管理员所有）；演示数据 owner=admin。

## 4. API 契约（v0.2 新增/变更）

所有错误格式沿用 `{"detail","code"}`。下列端点除注明公开外均需登录。

### 4.1 用户管理（admin）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/users?query=&role=&include_disabled=true&page=&page_size=` | `{items:[UserAdminOut], total}`；UserAdminOut = UserOut + `{recording_count, share_count}` |
| POST | `/api/users` | `{username,password(min 8),display_name?,email?,role?}` → 201 UserAdminOut；用户名重复 409 |
| PATCH | `/api/users/{id}` | `{display_name?,email?,role?,disabled?}`；不能撤销/停用最后一个管理员（400）；不能停用/降级自己导致无管理员 |
| POST | `/api/users/{id}/reset-password` | `{new_password(min 8)}` → `{ok:true}` |
| DELETE | `/api/users/{id}` | 不能删自己/最后一个管理员（400）；拥有录音时 409 `请先转移或删除该用户的录音`；其分享 created_by SET NULL |

### 4.2 分享（录音所有者或 admin）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/recordings/{id}/shares` | `{items:[ShareOut]}`，含已撤销（`revoked_at`） |
| POST | `/api/recordings/{id}/shares` | body `{password?, expires_at?, include_transcript=true, include_insights=true, allow_download=false}` → 201 ShareOut；password 4–64；expires_at 必须在未来；默认无过期 |
| GET | `/api/shares?recording_id=&include_revoked=false` | 当前用户（admin=全部）的分享列表 `{items,total}` |
| DELETE | `/api/shares/{id}` | 软撤销 → `{ok:true}`（幂等） |

`ShareOut`：
```json
{"id":1,"recording_id":1,"token":"...","url_path":"/s/...",
 "include_transcript":true,"include_insights":true,"allow_download":false,
 "has_password":false,"expires_at":null,"revoked_at":null,"expired":false,
 "view_count":3,"last_viewed_at":"...","created_at":"...",
 "created_by":{"id":1,"username":"admin","display_name":"管理员"}}
```

### 4.3 公开分享（无需登录）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/public/shares/{token}` | 200 `PublicShareOut`；无效/撤销/过期 → 404；密码保护时仍返回元数据（`has_password=true`）；每次成功请求 `view_count+1` |
| POST | `/api/public/shares/{token}/unlock` | `{password}` → `{ok:true,expires_in:7200}` 并设置 HttpOnly Cookie；错误密码 401；限速 429（每 IP+token 5 次/分钟） |
| GET | `/api/public/shares/{token}/media` | 需解锁（有密码时）否则 401；支持 Range → 206；`?download=1` 需 `allow_download` 否则 403 |
| GET | `/api/public/shares/{token}/transcript` | `include_transcript=false` → 403；结构同 `TranscriptOut` |
| GET | `/api/public/shares/{token}/insights` | `include_insights=false` → 403；结构同 `InsightsOut` |
| GET | `/api/public/shares/{token}/download` | `allow_download=false` → 403；原文件附件 |

`PublicShareOut`：
```json
{"share":{"include_transcript":true,"include_insights":true,"allow_download":false,
          "has_password":true,"expires_at":null,"created_at":"...","view_count":3},
 "recording":{"uuid":"...","title":"...","description":"...","media_type":"audio",
              "duration_ms":2437000,"recorded_at":"...","language":"zh",
              "speakers":[{"id":1,"label":"说话人1","display_name":"吴克强","color":"#5B8FF9"}],
              "tags":[{"id":1,"name":"论文","color":"#7C9CF5"}]}}
```
- Cookie：名称 `echoic_share`，JWT claims `{share_id, token, exp}`，`HttpOnly; SameSite=Lax; Path=/api/public/shares/{token}; Max-Age=7200`。跨多个分享互不影响。
- 公开页不提供 AI 问答、不暴露 owner/其他用户信息、不返回原始 uuid 之外的内部 ID。

### 4.4 consume（R-22）
- 配置（环境变量）：`ECHOIC_CONSUME_ENABLED=true`、`ECHOIC_CONSUME_DIR=<data>/consume`、`ECHOIC_CONSUME_INTERVAL_SEC=15`、`ECHOIC_CONSUME_OWNER_USERNAME=`（空=首个管理员）。
- 行为：worker 周期扫描目录顶层文件；稳定文件 → sha256 去重 → probe → 移动（同卷 rename，失败回退 copy+delete）到 `data/media/{uuid}/original.ext` → 创建 Recording（source=`consume`、title=文件名去扩展名、recorded_at=文件 mtime、owner=管理员）→ 入队 → `imported_files` 记录。失败文件移动到 `consume/failed/<原名>` 并写 `<原名>.error.txt`；重复文件跳过并计数。
- `GET /api/system/info`（admin）新增：
```json
"consume":{"enabled":true,"dir":"/data/consume","interval_sec":15,
           "pending_files":0,"failed_files":0,
           "last_scan":{"at":"...","scanned":2,"imported":1,"duplicates":1,"failed":0}}
```
- `POST /api/system/consume/scan`（admin）→ 立即扫描：`{ok:true, result:{scanned,imported,duplicates,failed}, at:"..."}`。
- 扫描绝不能让 worker 崩溃；单文件失败只影响该文件。

### 4.5 录音/列表变更
- `RecordingSummary` 新增 `owner_id: int|null`、`owner: {id,username,display_name}|null`（前端用于管理员展示/转移归属）。
- `PATCH /api/recordings/{id}` 新增可选 `owner_id`（**仅 admin** 可改；member 传 → 403；目标用户需存在）。
- 列表/搜索/仪表盘按当前用户过滤；统计数字也按权限范围计算。

### 4.6 设置变更
- `system.allow_registration`（bool，默认 false）：开放注册开关，仅 admin 可改；公开注册创建 member。
- 系统设置响应 `system` 增加 `allow_registration`、`consume:{enabled,dir,interval_sec}`（只读信息）。

## 5. 前端（R-17/R-18/R-22）

| 路由 | 说明 |
|---|---|
| `/users` | 仅 admin；用户管理表格 + 新建/编辑/重置密码/停用/删除对话框；非 admin 访问重定向到资料库并提示 |
| `/s/:token` | 公开分享页，无需登录；不套 AppShell；密码门；只读播放器 + 转写/AI纪要/观点树/章节（按 share 开关）；过期/撤销页；底部“由 Echoic 提供” |
| 详情页「分享」 | ShareDialog：创建（密码/过期/开关/下载）+ 链接复制 + 已创建分享管理（撤销） |
| `/settings` | 系统页新增：开放注册开关、consume 目录/间隔信息 + “立即扫描”按钮（admin）；member 路由不可见 |
| 全局 | AppShell 按 role 隐藏“用户管理”（admin 显示）与设置入口（仅 admin）；用户菜单显示角色；member 空库文案“还没有你自己的录音，上传或录制第一条” |

公开页错误处理：404 → “分享链接不存在或已失效”；401（需密码）→ 密码门；“链接已过期/已撤销”；无 include 的页签隐藏。公开页 401 不得触发跳转 `/login`。

## 7. 实现注记（2026-10-27，v0.2.0 落地）

- `GET /api/auth/me` 保持 v0.1 包装 `{"user": UserOut}`，UserOut 增量增加 `role/email/disabled/last_login_at`。
- 公开分享无效/撤销/过期一律 **404**；密码分享在未解锁时，metadata 可读，但 media/transcript/insights/download 均 401。
- `ShareCreateIn.password` 接受 4–64 字符；开放分享请**省略 password 字段**（传空串会 422）。
- `view_count` 在 metadata、media、download 请求时递增（每次请求 +1）；`last_viewed_at` 同步更新。
- 管理员删除用户时，其创建分享的 `created_by` 置 NULL，分享本身仍有效（由录音所有者/管理员管理）。
- 成员视角下标签目录全局可见，但标签的录音计数与仪表盘 top_tags 仅统计自己的录音。
- consume 重复内容保留在目录中并在扫描结果计数；不支持扩展名/隐藏文件/临时文件静默跳过；无效媒体移入 `consume/failed/` 并写 `.error.txt`。
- 注册仅提供开关 + `POST /api/auth/register`，v0.2 暂无注册页面。
