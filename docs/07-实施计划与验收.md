## 2. 技术方案摘要

浏览器（React 18 + TS + Vite + AntD 5）同源访问 FastAPI；FastAPI 单进程同时提供 REST/SSE 与前端静态资源，内嵌 worker 轮询 `jobs` 表；数据落 SQLite（WAL）与 `/data` 卷；ASR/LLM/Embedding 通过注册表选择，仅出站调用用户配置的服务。

| 决策 | 选择 | 理由 / 约束 |
|---|---|---|
| 交付形态 | 单容器，FastAPI 托管前端静态资源 | 不强制 nginx/Redis/Postgres；`compose up` 即用 |
| 数据库 | SQLite（WAL）默认，Postgres 可选 | 个人/小团队足够；写并发靠短事务 + 单 worker |
| 任务队列 | `jobs` 表 + 内嵌线程 | 持久化、可恢复、可重试；无额外中间件 |
| AI 抽象 | ASR/LLM/Embedding Protocol + 注册表 | 换供应商不改业务；Mock 支撑离线测试/演示 |
| 流式问答 | SSE（`start/delta/citations/done/error`） | 比 WebSocket 简单，穿透代理友好 |
| 密钥 | Fernet 加密，接口只回掩码 | 密钥不落日志；`__clear__` 显式清除 |
| 前端 | TanStack Query + 少量 Zustand | 服务端状态与 UI 状态分离；契约见 `API.md` |

> 详细契约以 `ARCHITECTURE.md`、`API.md`、`PIPELINE.md`、`FRONTEND.md` 为准；本计划不重复定义字段。

### 6.4 安全测试清单

- [ ] 未登录访问受保护接口 → 401；越权访问他人录音 → 404/403（单用户也校验 owner）。
- [ ] 响应/日志不含明文 Key；DB 密钥为密文；设置接口只回掩码；登录限速、JWT 过期/篡改被拒。
- [ ] 上传伪装扩展名被 ffprobe/类型校验拒绝；超大文件 413；路径穿越不能越出 data，存储名用 uuid。
- [ ] Markdown 不执行原始 HTML/脚本；引用转义；`base_url` 仅 http/https 且仅管理员可改。
- [ ] 媒体接口鉴权；Range 越界 416；`download=1` 文件名安全。

### 6.5 性能抽查

- 造 5000 条录音/5 万条片段，列表首屏与翻页 P95 < 500ms。
- 40 分钟音频：首字节 <1s；随机 seek 10 次均 <200ms；转写滚动无明显掉帧。
- 500MB 上传流式落盘、内存不线性增长；处理轮询不造成锁等待，上传仍可响应。
